# SDLC 스킬 forward-eval

`forward-cases.json`은 결정론적 도구가 아니라 **스킬의 판단과 행동**을 평가한다. 독립 에이전트에
각 케이스의 `skill`·`request`와 격리된 임시 레포만 주고 실행 결과를 관찰한다. 의도한 답이나
과거 결함은 알려주지 않는다.

각 `must`를 다음처럼 채점한다.

- 2: 결과물과 행동에서 확인됨
- 1: 설명에는 있으나 결과로 확인되지 않음
- 0: 누락 또는 반대 행동

케이스별 만점의 80% 이상이고 0점 항목이 없어야 통과다. 파일 변경, 커밋, 훅 출력과 최종 보고를
함께 보며 문구 일치만으로 통과시키지 않는다. 외부 push·PR·실서비스 변경은 평가 범위에서 제외한다.

결과는 다음 형태로 저장하고 채점기를 실행한다.

```json
{
  "model": "<모델>",
  "date": "YYYY-MM-DD",
  "cases": [
    {
      "id": "intent-stops-at-review",
      "scores": [2, 2, 2],
      "evidence": ["<관찰 증거>", "<관찰 증거>", "<관찰 증거>"]
    }
  ]
}
```

```sh
node forward-eval.mjs --list
node forward-eval.mjs <results.json>
```

이 평가는 모델 실행 환경이 필요하므로 `run.mjs`의 로컬 회귀 평가와 분리한다. 스킬을 크게
바꾸거나 모델을 교체할 때 독립 실행하고 결과를 날짜·모델·케이스별 점수로 남긴다.
