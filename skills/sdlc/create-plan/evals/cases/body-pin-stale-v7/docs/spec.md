# Spec: 보관 문서 검색 제외

## 시나리오 `[필수 · standard+]`

### SCN-001 — 기본 검색

- **Given** 보관된 문서와 보관되지 않은 문서가 각각 하나씩 색인돼 있다
- **When** 운영자가 둘 다 걸리는 낱말로 검색한다
- **Then** 보관되지 않은 문서만 결과에 선다

### SCN-002 — 보관 포함 검색

- **Given** 같은 상태
- **When** 운영자가 보관 포함을 켜고 같은 질의를 보낸다
- **Then** 두 문서가 모두 선다

## 요구사항

### FR-001 — 기본 검색은 보관 문서를 뺀다 `Must`

근거: OUT-001

검색 질의는 별도 지시가 없으면 보관된 문서를 결과에서 제외한다. 보관 필드가 없는 옛 문서는 «보관 아님» 으로 읽는다.

수용 기준:

- [ ] AC-001 — 보관 문서와 일반 문서가 함께 걸리는 질의에서 일반 문서만 반환된다
- [ ] AC-002 — 보관 필드가 없는 문서는 결과에 그대로 남는다
- [ ] AC-004 — 보관 여부를 읽지 못하면 질의가 실패하지 않고 그 문서를 결과에 남긴다

### FR-002 — 보관 포함 플래그 `Should`

근거: OUT-002

호출자가 보관 포함을 요청하면 보관 문서도 결과에 넣는다. 기본값은 거짓이다.

수용 기준:

- [ ] AC-003 — 플래그가 켜지면 보관 문서와 일반 문서가 모두 반환된다

## 오류와 경계

### EDGE-001 — 결과가 전부 보관 문서라 빈 결과가 된다

빈 결과를 그대로 낸다. 사용자에게: 결과가 없으며 보관 포함을 켜 볼 수 있다고 알린다. 복구: 자동
