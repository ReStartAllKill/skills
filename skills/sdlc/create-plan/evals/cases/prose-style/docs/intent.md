# Intent: 검색에서 보관 문서를 뺀다

## 문제 `[필수 · 모든 티어]`

이 문서는 검색의 문제를 설명한다. 아래에서는 그 배경을 다룬다. 보관된 문서는 시스템에 의해 걸러지지 않게 된다. 운영자는 이를 손으로 거르는 시간을 필요로 한다.

## 목표 결과 `[필수 · 모든 티어]`

### OUT-001 — 기본 검색에 보관 문서가 안 뜬다 `Must`

시스템은 보관 상태를 반영한 검색을 제공한다. 질의는 색인을 조회하는 역할을 수행한다. 색인은 보관 필드를 가진다. 그 필드는 대부분의 문서에 이미 채워져 있으나 질의가 그것을 보지 않는다. 그래서 결과가 섞이고 운영자로 하여금 매번 같은 작업을 되풀이하게 한다. 이것은 검색 품질의 문제라고 할 수 있다.

확인: 보관 문서와 일반 문서를 하나씩 만들고, 둘 다 걸리는 낱말로 검색해 일반 문서만 나오는지 본다.

### OUT-002 — 필요하면 보관 문서도 볼 수 있다 `Should`

보관 포함을 켜면 둘 다 나온다.

확인: 같은 질의를 플래그를 켜고 돌린다.

## 비목표 `[필수 · 모든 티어]`

- 보관 정책 자체는 바꾸지 않는다.
- 보관 문서의 열람 권한은 손대지 않는다.

## 제약 `[필수 · 모든 티어]`

### CON-001 — 검색 API 응답 형태를 바꾸지 않는다

다른 소비자가 이미 붙어 있다. 형태를 바꾸면 그쪽이 조용히 깨진다.

## 열린 질문 `[필수 · 모든 티어]`

해당 없음 — 보관 필드는 이미 색인에 있고 동작만 정하면 된다.
