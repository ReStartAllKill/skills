# Intent: 신청자가 집행 전 신청을 스스로 취소한다

## 문제

취소 창구가 CS 뿐이라 취소 1건에 평균 2.3영업일이 든다. 그동안 신청은 심사 큐에 남아 심사 인력이 이미 취소된 건을 본다.

### 증거

- CS 티켓 «취소 요청» 이 지난 30일 동안 42건이다.

## 목표 결과

### OUT-001 — 신청자가 집행 전 신청을 취소한다 `Must`

신청자가 화면에서 취소하면 신청이 심사 큐에서 빠진다.

확인: 대기 중 신청을 취소하고 큐 조회에서 빠졌는지 본다.

### OUT-002 — 취소 사유가 남는다 `Should`

취소할 때 사유를 고르면 CS 가 그 사유를 본다.

확인: 사유를 골라 취소하고 CS 화면에서 사유를 본다.

## 비목표

- 집행 후 중도상환은 다루지 않는다.

## 제약

### CON-001 — 집행된 신청은 어떤 경로로도 취소되지 않는다

집행은 자금이 나간 뒤라 되돌리면 회계가 어긋난다.

## 가정

### ASM-001 — 심사 큐는 신청 상태를 읽어 걸러진다

큐가 별도 복제본을 들고 있으면 상태만 바꿔서는 빠지지 않는다.
