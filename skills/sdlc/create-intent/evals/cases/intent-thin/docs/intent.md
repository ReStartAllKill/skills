# Intent: 검색에서 보관 문서를 뺀다

## 문제 `[필수 · 모든 티어]`

이 문서는 검색의 문제를 설명한다. 보관된 문서는 시스템에 의해 걸러지지 않는다. 결과를 눈으로 걸러내느라 검색이 느려지고, 보관했다는 사실 자체가 화면에서 안 보인다.

## 목표 결과 `[필수 · 모든 티어]`

### OUT-001 — 검색 경험을 개선한다 `Must`

검색이 충분히 빠르게 동작하고 결과가 적절히 걸러진다.

확인: 보관 문서와 일반 문서를 하나씩 만들고, 둘 다 걸리는 낱말로 검색해 일반 문서만 나오는지 본다.

### OUT-002 — 필요하면 보관 문서도 볼 수 있다 `Should`

보관 포함을 켜면 둘 다 나온다.

확인: 같은 질의를 플래그를 켜고 돌린다.

## 비목표 `[필수 · 모든 티어]`

- 보관 정책 자체는 바꾸지 않는다.
- 보관 문서의 열람 권한은 손대지 않는다.

## 제약 `[필수 · 모든 티어]`

### CON-001 — 검색 API 응답 형태를 바꾸지 않는다

다른 소비자가 이미 붙어 있다. 형태를 바꾸면 그쪽이 조용히 깨진다.

## 열린 질문 `[필수 · 모든 티어]`

해당 없음 — 보관 필드는 이미 색인에 있고 동작만 정하면 된다.
